# Dummy Engagement Invitation

A standalone HTML/CSS/JavaScript engagement invitation designed for GitHub Pages.

## Files

- `index.html` — page structure and dummy invitation data
- `style.css` — responsive styling
- `script.js` — loading screen, music button, and developer API demo

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will publish the site at your repository's Pages URL.

The site is fully static and does not require a server, database, PHP, Python, or Node.js.
