# Tanya & Ashutosh — Wedding Invitation

A responsive wedding invitation website built with plain HTML, CSS and JavaScript, ready for GitHub Pages.

## Files

- `index.html` — page structure and invitation content
- `style.css` — responsive wedding design
- `script.js` — countdown, mobile menu, scroll animations and back-to-top
- `assets/hero-wedding.png` — wedding illustration used in the hero/gallery

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

No backend or build step is required.

## Customize

Replace `assets/hero-wedding.png` with your own wedding illustration/photo if desired.

For additional gallery photos, put them inside `assets/` and update the `<img>` elements in `index.html`.
